**Analista de Datos Jr. — Área Comercial**

Buscamos una persona analista para sumarse al equipo comercial de una cadena de supermercados.

**Requisitos**
- Estudiante avanzado o graduado de Economía, Estadística, Sistemas o carreras afines.
- SQL (consultas con joins y agregaciones).
- Python o R para análisis de datos.
- Inglés intermedio para lectura de documentación.
- Manejo de Power BI o Tableau.
- Buena predisposición.
- Ganas de aprender.

**Ofrecemos**
- Capacitación continua.
